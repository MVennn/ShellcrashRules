## 本版内容

**脚本**

- 修复 看门狗不看内存 —— `config/starts/start_legacy_wd.sh` 拉起前先调 `memgate.sh`，内存不足时跳过本轮，避免「OOM → 拉起 → 再 OOM」的循环。

**文档**

- 修复 出口策略口径 —— `docs/PITFALLS.md` 的「绝不降级到非印度节点」改为「台湾优先、印度兜底」，与 2026-10-21 的实测一致。
