## 本版内容

**策略组**

- 新增 `🎬 B站解锁` —— select，默认香港；只有 B站 API 域走它，评论与主页的 IP 属地显示节点所在国家。
- 新增 `📺 大流量` —— select，默认公共池；大文件下载、游戏补丁、驱动、视频站点与 Telegram 走它，跑不满时由 `bulk-guard.sh` 切回机场。
- 新增 `🔗 GitHub 出口` —— url-test，按 GitHub 真实可达性选路，与只服务 Google 的干净出口分开。

**规则**

- 新增 B站段 —— `api.bilibili.com` / `biliapi.com` / `biliapi.net` 出国；播放 CDN（`bilivideo` / `hdslb` / `biliimg` / MCDN）直连，视频不再占用机场流量；评论与动态接口直连。
- 新增 大流量段 —— HuggingFace、GitHub 发布包、NVIDIA/AMD 驱动、暴雪 / GOG / EA / 育碧 / Steam / Epic、Maven。
- 新增 视频站点与 Telegram 段 —— 成人站及其自有 CDN、Telegram 媒体与 DC 段。
- 修复 Google 广告 —— `doubleclick` / `googlesyndication` / `analytics` 等回到广告拦截，不再被宽泛 Google 规则遮蔽。
- 修复 B站 IPv6 —— 撤回会打断 QQ / 微信视频的联通大段；IPv6 规则改按 `br-lan` 入接口，换前缀后不失效。

**工具**

- 调整 公开节点筛选 —— 三个数据源轮转；「每协议 / 每网段上限」改为参数；运行期间自动暂停守护，避免并发生成坏配置。
- 修复 公开节点筛选 —— 批次测试异常时回滚旧配置；重启后先等 API 就绪；SSH 传输失败重试；预检失败用二分定位坏节点并记 dead。
- 修复 规则钩子权限 —— 用 `cp -p` 保持原权限位，PC 侧复现不再静默退回 umask。
- 修复 凭据扫描 —— 占位符只豁免匹配片段，示例与真值同行时真值仍会报。
