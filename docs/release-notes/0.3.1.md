## 本版内容

**防火墙**

- 修复 CN QUIC 豁免 —— `cn_ip6_mirror` 集合始终定义（元素可为空），未开 IPv6 / fake-ip 的设备不再因为「引用未定义集合」导致整份 nft 校验失败。
- 修复 VM 劫持守卫 —— `$$vm_ipv4` 恒真导致空集合链被创建；改回 `$vm_ipv4`。

**订阅与规则**

- 修复 伪节点过滤 —— 不再用单独的「流量」关键字误杀「大流量专线」这类真实节点。
- 清理 生成器 —— 删除 `googleapis.com → 节点选择` 这条永远被去重丢弃的死规则。

**自检**

- 修复 自修复复核 —— 钩子/QUIC 补丁插入后重新 grep 确认，锚点变了会报 FAIL 而不是假报「已修复」。
- 修复 secret 读取 —— 剥掉配置里的引号，`secret='abc'` 时 API 查询不再全部 401。
- 修复 每日自检备份 —— 看门狗暂停备份移到 overlay，路由器重启不会把「已暂停」状态固化。

**仓库**

- 修复 密钥扫描 —— 本机路径只豁免命中片段。
- 修复 离线去重工具 —— 用 `cp -p` 保留原文件权限。
- 部署 —— `starts/sub-sync.sh` 纳入 `local-patches` 与设备 `PATCH_SPEC`，ShellCrash 官方更新后能一起恢复。
