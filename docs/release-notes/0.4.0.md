## 本版内容

**分流规则**

- 调整 Steam 下载 —— `steamserver.net`（CM）、`api.steampowered.com`（内容服务器目录）、国内 CDN（`eccdnx.com` / `clngaa.com` / `pphimalayanrt.com`）、`steamcontent.com` 全部直连。
- 调整 Steam 静态资源 —— `steamstatic.com`、`steamcdn-a.akamaihd.net`、`steampipe*.akamaized.net` 从 `📺 大流量` 挪到 `🚀 节点选择`。
- 调整 DNS —— `api.steampowered.com` 不再走 fake-ip，并指定国内 DNS 解析（默认 DoH 会把它解析到海外 Akamai 边缘，直连连不上）。

**为什么改**

- Steam 的内容服务器目录按「客户端公网 IP」分配 CDN。CM 走代理时 Valve 看到的是香港 IP，只给香港/东京节点（43–183 Mbps）。
- CM 改直连后 Valve 看到真实国内 IP，分配国内 CDN，且这些 IP 在防火墙层就绕过代理走硬件转发，实测 375–390 Mbps。

**已知限制**

- `api.steampowered.com` 直连会偶发超时，客户端会自动重试；成功一次即可拿到国内服务器列表。
- CM 直连到香港/新加坡的延迟比走机场高（TLS 0.97s vs 0.35s），换来的是下载带宽翻倍。
