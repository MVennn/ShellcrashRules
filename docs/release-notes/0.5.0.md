## 本版内容

**分流规则**

- 调整 游戏补丁/下载 CDN —— Epic / 暴雪 / GOG / EA / 育碧 / Xbox / Riot / Rockstar / Bethesda 共 26 条由 `📺 大流量` 改 `🎯 全球直连`：实测这些域全部解析到境外边缘节点、直连可达，「各有国内 CDN」不成立，但它们也不该占公共池。
- 调整 `📺 大流量` 补 9 条正文域 —— 容器镜像（docker/cloudflare/quay）、网盘（mega/dropbox）、模型权重（HF）等 blob/CDN 域进大流量组；登录与 API 仍留各自机型组。
- 调整 `opencode.ai` / `workbuddy.ai` 改 `🎯 全球直连` —— 带真实 key 实测 26 个型号直连 200（只有地区受限的少数型号 403）；机场只留给地区受限型号兜底。

**新入站**

- 新增 `ai-airport` 入站（http://127.0.0.1:7896，固定走 `🤖 AI接口` 出口、不看规则）—— 专供 zgate 的分步代理链当兜底跳用；经它出口为日本节点，与路由器直连出口可并存。

**节点健康**

- 调整 `🤖 AI接口` 复测间隔 300s → 60s（`timeout: 5000`）—— 节点进坏态后最长 5 分钟才换，这段窗口所有请求都压在死路上；缩短复测才是对的杠杆，不动组成员。
- 调整 健康检查 URL 首页 → `robots.txt` —— 首页 70 KB、24 个成员按 60s 复测约 2.4 GB/天；robots.txt 只有 220 B，降到约 8 MB/天。

**自检**

- 修复 每日 05:05 自检误报 —— 三条「吸收段」预期对齐 10-30 生成器现值（此前每天必 FAIL 三条）；规则文件与生成器一字未动。

**仓库**

- `check-secrets.py` / `check-docs.py` 同步系列仓已修的守卫漏报与误报；本仓分叉差异保留。
- 文档 —— TROUBLESHOOTING 补「mihomo 组被 PUT 钉住时用 DELETE 解钉」（v1.19.28 实测 204，重启不清 fixed）。
