## 本版内容

**分流规则**

- 新增 自定义策略组 —— `🤖 AI接口`（url-test 打 opencode.ai，容差 50ms 不换节点）、`🤖 AI网页`（select，钉印度）、
  `🤖 干净出口`（select，唯一经 Google 侧地区判定为非 CN 的稳定出口），外加印度 / 加拿大 / 德国 / 英国四个地区组。
- 新增 AI 分流规则生成器 —— `config/generators/ai-rules-update.sh` 拉 MetaCubeX geosite 的
  `category-ai-chat-!cn` 分类，生成 `config/generated/rules.yaml`，并追加「分类修正层」
  （广告优先 → AI 语义修正 → Bing/Copilot → OneDrive/SharePoint → Sentry/Disney → CN 例外）。
- 新增 内核参数 —— `tcp-concurrent: true`、`find-process-mode: "off"`、
  `profile.store-fake-ip: true`、`profile.store-selected: true`（缺最后一项，重启后干净出口组会被重置成第一个成员）。
- 新增 印度备用入口 —— `🇮🇳 印度-备用m2` / `🇮🇳 印度-备用ct2`，与订阅入口同端口同 Host、同一出口 IP，
  用于绕开订阅入口对大页面的吞吐塌陷。
- 调整 CN 直连中间层 —— `config/hooks/rules-mid.sh` 在生成配置里把 `RULE-SET,cn,🎯 全球直连`
  插到最后一条电报规则之后、第一条国外媒体规则之前，宽泛代理不再抢 CN 域名。
- 调整 策略组去重重排 —— `config/hooks/reorder-groups.sh` 清同名组、清组内重复 key、重排成员顺序、
  归一 `mixed-port`。

**防火墙**

- 新增 全局 QUIC 阻断 —— `firewall/tables/quicguard.nft` 拒绝 UDP `{443, 8443, 4433, 5226, 5228, 8081, 8883, 19302}`，
  浏览器回落 TCP，Google 端点不再带国内出口 IP 直出。
- 新增 Google 国内边缘段重定向 —— `firewall/tables/googlecn.nft` 把 LAN 发往 `203.208.32.0/19`
  与 `2401:3800::/32` 的 TCP 重定向进代理，让域名规则有机会生效。
- 新增 DNS 劫持与推送端口 —— `firewall/tables/googleroute.nft` 把 LAN 的 53 端口重定向到 mihomo DNS、
  把 Google 推送端口与 fake-IPv6 段送进代理；加载前需等 DNS 端口就绪。
- 调整 代理端口集 —— 额外纳入 FCM 5228 与 DoQ 19302，否则这两类真实 IP 目标会直连暴露国内出口 IP。

**工具**

- 新增 规则审计 —— `tools/rule_audit.py` 离线计算每条域名规则的**真实生效目标**，
  输出精确冲突、顺序遮蔽、广告误伤与代表域名归类；基线为 139 个代表域名 0 异常。
- 新增 mihomo 链路诊断 —— `tools/diagnose/` 下 7 个脚本：控制 API 客户端、实时日志抓取、
  QQ CDN 连通性分阶段探测、DNS 通道判定、域名分类、规则命中观察、QUIC 能力探测。
- 新增 节点延迟探测 —— `tools/latency/latency_probe.py`，只读 `/proxies` 与 `/proxies/{name}/delay`，不切组。
- 新增 流式规则扫描 —— `tools/scan_rules.py`，流式扫 `/rules` 全量展开规则并提取指定域名相关条目。

**运维脚本**

- 新增 AI 接口自检 —— `config/ai-api-check.sh` 共 16 段：策略组状态、延迟、三协议最小 token、
  钩子与 hotupdate 路径、fake-ip 过滤、QUIC 与 TLS 重解析、Google 统一出口、规则文件完整性等；
  部分段带自动修复。订阅更新后必跑。
- 新增 每周自动更新 —— `config/generators/auto-update.sh`（cron `30 4 * * 0`）：
  先生成规则、成功才热更新订阅，失败则跳过热更新，避免把半成品规则推到线上。
- 新增 更新后恢复 —— `config/post-sc-update.sh`：ShellCrash 官方脚本更新会覆盖 `starts/` 下三个带补丁的文件，
  该脚本按标记串恢复并补回 cron 生命线。

**仓库**

- 新增 根门面 —— README 说明这是什么、适用环境、怎么跑、目录与配置生成链路。
- 新增 文档体系 —— docs/ 建唯一索引与四类分区；新增架构、踩坑、排错、维护、文档规则五篇正本。
- 新增 第三方声明 —— NOTICE 列出 ShellCrash、mihomo / Clash.Meta、MetaCubeX meta-rules-dat、OpenWrt 的来源与许可证。
- 调整 目录结构 —— 配置与脚本归 `config/`、nft 表归 `firewall/tables/`、工具归 `tools/`、
  文档归 `docs/`；一次性诊断脚本与调试残留分别归入各自的 `archive/`。
