## 本版内容

**节点**

- 新增 HY2 自动同步 —— 每次生成配置前（启动 / 拉订阅）从机场原始订阅补齐 Hysteria2 节点，写进 `proxies.yaml` 的 `# >>> HY2-AUTO` 块；6 小时节流，拉取失败保留旧块。
- 修复 干净出口选不到新加坡 —— `🤖 AI网页` / `🤖 干净出口` 的 filter 纳入新加坡节点，HY2 池才进得来。

**规则**

- 新增 `z.ai` / `bigmodel.cn` 直连 —— ZCode 账号与项目 Token API 不再绕香港出口，实测 0.34s（原路径 15s 超时）。

**为什么之前换节点无效**

机场按客户端 UA 给节点集（只有 `clash.meta` 才给 Hysteria2），订阅转换器又不认 hysteria2 —— 唯一被判 `cc=SG` 的那批节点在路由器上整类不可见。vmess 池（含「新加坡-优化3」）整池 `cc=CN`。
